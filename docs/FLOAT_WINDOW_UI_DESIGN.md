# 悬浮窗 UI 设计（GG 风格）

> 完全采用 GameGuardian 修改器的 UI 框架和布局。
> 4 个标签页：搜索 / 内存 / 保存 / 设置。断点、日志、进程功能合并到对应页面。

---

## 一、整体框架

```
悬浮球 (54dp 圆形 "GG")
  │ 点击展开/收起
  ▼
悬浮窗 (宽=屏宽85%, 高=屏高65%)
┌──────────────────────────────────────┐
│ 🔍 GG  com.tencent.tmgp.sgame  [_][X] │  ← 标题栏：图标+进程名+最小化+关闭
├──────────────────────────────────────┤
│ [搜索] [内存] [保存] [设置]            │  ← 标签栏（4个，GG原版就4个）
├──────────────────────────────────────┤
│                                      │
│         内容区（切换）                 │
│                                      │
├──────────────────────────────────────┤
│ 结果: 4  已选: 0  冻结: 0             │  ← 底部状态栏
└──────────────────────────────────────┘
```

**和旧布局的区别**：
- 标签从 6 个减到 **4 个**
- 断点 → 合并到内存页（长按地址→"什么访问了这个地址"）
- 标注 → 改名为"保存"，按 GG 保存列表风格
- 日志 → 去掉标签，改浮动通知 + 设置页日志入口
- 进程 → 合并到设置页（引擎状态 + 选择进程）

```

│ 🔍 GG  com.tencent.tmgp.sgame  [_][X] │
└──────────────────────────────────────┘
```

- 左侧：GG 图标（16dp）+ "GG" 文字
- 中间：当前进程名（未附加时显示"未选择进程"）
- 右侧：最小化按钮 `_`（收起悬浮窗，保留悬浮球）+ 关闭按钮 `X`（停止服务）
- 背景：`#FF1E6FBA`（GG 纯蓝）
- 高度：36dp
- 整个标题栏可拖动悬浮窗位置

## 四、搜索页（核心页）

```
┌──────────────────────────────────────┐
│ ┌──────────────────────────────────┐ │
│ │  30                              │ │  ← 大输入框，占满宽度
│ └──────────────────────────────────┘ │
│                                      │
│ [搜索] [重置] [更多▼]                 │  ← 搜索按钮行
│                                      │
│ 类型: [DWORD][WORD][BYTE][QWORD]     │  ← 横向滚动小方块
│       [FLOAT][DOUBLE][AUTO]          │
│                                      │
│ 内存: [匿名▼]  对齐: [4字节▼]         │  ← 搜索选项（"更多"展开）
│                                      │
│ ┌────┬──────────┬──────┬────┬─────┐ │
│ │ ☐  │ 地址      │ 值   │区域│冻结 │ │  ← 结果列表表头
│ ├────┼──────────┼──────┼────┼─────┤ │
│ │ ☐  │7f123400  │ 30   │anon│  ☐  │ │
│ │ ☐  │7f567800  │ 30   │anon│  ☐  │ │
│ │ ☐  │7f9abc00  │ 30   │heap│  ☐  │ │
│ └────┴──────────┴──────┴────┴─────┘ │
│                                      │
│ refine: [+增加] [-减少] [=未变] [≠变化]│  ← refine四键，有结果后显示
└──────────────────────────────────────┘
```

### 4.1 输入框

- 高度：48dp（GG 原版输入框很大，方便弹数字键盘）
- 背景：`#FF1A1A2E`，圆角 4dp
- 文字：20sp，白色，等宽字体
- 提示文字："输入搜索值"，灰色
- 点击弹出数字键盘

### 4.2 搜索按钮行

- `搜索`：主按钮，`#FF1E6FBA` 背景，白色文字
- `重置`：次按钮，`#FF2A2A3E` 背景，灰色文字
- `更多▼`：次按钮，点击展开/收起高级选项

### 4.3 类型选择

- 横向 `HorizontalScrollView`，每个类型是一个小方块
- 选中：`#FF1E6FBA` 背景 + 白色文字
- 未选中：`#FF2A2A3E` 背景 + 灰色文字
- 类型：BYTE / WORD / DWORD / QWORD / FLOAT / DOUBLE / AUTO
- 每个方块：宽 56dp，高 28dp，文字 11sp

### 4.4 高级选项（"更多"展开）

- 内存范围：下拉选择（匿名/全部/Java堆/C++堆/栈/代码段/自定义范围）
- 对齐方式：下拉选择（1字节/2字节/4字节/8字节/未对齐）
- 搜索模式：精确/模糊（模糊时隐藏输入框，显示"变化/未变化"按钮）

### 4.5 结果列表（5 列）

| 列 | 宽度 | 内容 | 颜色 |
|---|---|---|---|
| 勾选 | 32dp | CheckBox | `#FF4CAF50` 选中绿 |
| 地址 | weight=1.5 | `7f123400`（8hex，不带0x） | `#FF64B5F6` 浅蓝 |
| 值 | weight=1 | `30` | 白色 |
| 区域 | weight=0.8 | `anon`/`heap`/`stack`/`code` | `#FF81C784` 浅绿 |
| 冻结 | 32dp | CheckBox | `#FF4CAF50` 选中绿 |

- 行高：36dp
- 点击行：弹出修改值对话框
- 长按行：弹出菜单（修改/冻结/添加到保存/跳转内存/删除）
- 列表为空时显示提示："搜索结果将显示在这里"

### 4.6 refine 四键（有结果时显示）

- 显示在结果列表下方
- `+增加` / `-减少` / `=未变` / `≠变化`
- 每个按钮：宽 0dp weight=1，高 32dp，文字 12sp
- 背景：`#FF2A2A3E`，按下 `#FF1E6FBA`

## 五、内存页（hex 编辑器 + 断点）

```
┌──────────────────────────────────────┐
│ ◀ 0x7F1234000 ▶  [跳转] [+添加]       │  ← 地址导航栏
├──────────────────────────────────────┤
│ 地址      hex                     ASCII│
│ 7F123400 1E 00 00 00 1E 00 00 00  ..│  ← 每行16字节
│ 7F123408 00 00 80 3F 00 00 00 00  ..?│
│ 7F123410 78 56 34 12 00 00 00 00  xV4│
│ 7F123418 00 00 00 00 00 00 00 00  ...│
│ ...                                  │
├──────────────────────────────────────┤
│ 选中: 0x7F123400  DWORD=30            │
│ [修改] [断点] [搜索] [保存] [跳转]     │  ← 长按地址弹出操作栏
└──────────────────────────────────────┘
```

### 5.1 地址导航栏

- `◀`：上一页（-16字节）
- 地址显示：`0x7F1234000`，可点击编辑
- `▶`：下一页（+16字节）
- `跳转`：弹出对话框输入地址
- `+添加`：当前地址添加到保存列表

### 5.2 hex 编辑器（三栏）

用 `RecyclerView`，每行 16 字节：

| 栏 | 宽度 | 内容 | 颜色 |
|---|---|---|---|
| 地址 | 90dp | `7F123400`（8hex） | `#FF64B5F6` 浅蓝 |
| hex | weight=2 | `1E 00 00 00 ...`（16字节，每字节空格分隔） | `#FF81C784` GG绿 |
| ASCII | weight=1 | `..?xV4...`（可打印字符显示，不可打印显示`.`） | `#FFB0B0B0` 灰色 |

- 行高：28dp，文字 11sp，等宽字体
- 点击某字节：选中高亮（`#331E6FBA` 背景）
- 长按某行：弹出操作栏

### 5.3 操作栏（长按地址弹出）

底部弹出，5 个按钮：
- `修改`：修改选中地址的值
- `断点`：对该地址下硬件断点（读/写/读写/执行），替代原独立断点页
- `搜索`：以该地址的值为搜索条件搜内存
- `保存`：添加到保存列表，可输入描述
- `跳转`：跳转到该指针指向的地址

### 5.4 断点状态

下了断点的地址，hex 编辑器中该行左侧显示红色圆点 `🔴`，点击圆点查看命中历史。

断点命中时：
- 悬浮窗顶部弹出红色通知：`⚡ 断点命中! 0x7F123400 被写入`
- 点击通知跳转到内存页对应地址，展开命中详情（寄存器 + 反汇编）

## 八、浮动通知（替代独立日志页）

AI 操作或断点命中时，悬浮窗顶部弹出临时通知：

```
┌──────────────────────────────────────┐
│ ⚡ 断点命中! libil2cpp.so+0x12345    │  ← 红色背景，2秒后自动消失
├──────────────────────────────────────┤
│ ...正常页面内容...                    │
```

通知类型：
- **命令**：灰色背景，`gg_search → 25431 条`，1.5秒消失
- **断点命中**：红色背景 `#FFFF0000`，`⚡ 断点命中! 0x7F...`，3秒消失，可点击跳转
- **标注新增**：绿色背景 `#FF4CAF50`，`✓ 已保存: 当前子弹`，2秒消失
- **错误**：橙色背景，`✗ 搜索失败: 未附加进程`，3秒消失

通知从顶部下滑进入，停留后上滑消失。最多同时显示 1 条，新通知替换旧通知。

## 十二、交互规范

1. **悬浮球**：点击=展开/收起，拖动=移动位置，移动<10dp 判定为点击
2. **悬浮窗拖动**：仅标题栏区域可拖动
3. **悬浮窗缩放**：右下角 ◢ 拖动（可选，GG 原版固定尺寸）
4. **标签切换**：点击即切换，当前标签白色+下划线
5. **搜索页**：输入值→点搜索→游戏内变化→点 refine（增加/减少/未变/变化）→结果列表
6. **结果行**：点击=修改值，长按=菜单（修改/冻结/保存/跳转/删除）
7. **内存页**：点击字节=选中，长按行=操作栏（修改/断点/搜索/保存/跳转）
8. **保存行**：点击=修改值，长按=菜单（编辑描述/修改/冻结/跳转/删除）
9. **断点命中**：浮动通知弹出，点击跳转内存页对应地址
10. **返回键**：悬浮窗展开时按返回只收起悬浮窗，不退出 App
11. **进程未附加**：搜索/内存/保存页显示"请先在设置中选择进程"

## 十四、实现记录（2025 按本设计落地）

已按本设计重构 APK 悬浮窗（`apk/` 目录），构建通过并实机验证。与设计的偏差/落点说明：

**进程列表（设置→选择进程）**：`gg_list_processes` 的 `name` 即包名（读 `/proc/PID/cmdline`）。对话框按**应用优先**展示：隐藏内核线程（`[kworker...]`），含 `.` 的包名进程排前并解析**应用中文标签**（`PackageManager.loadLabel`，如「王者荣耀」，`:remote` 等进程后缀自动剥离），系统进程沉底；行 = 标签 + 包名 · PID。

**引擎约束导致的实现取舍**（agentd wire 协议能力有限）：- **内存范围**：引擎仅支持 匿名/可写/全部 三种 region 码；UI 保留设计 7 项，其中 Java堆/C++堆/栈/代码段/自定义范围 映射为「全部」。
- **AUTO 类型**：引擎无 AUTO，选择 AUTO 搜索时回退 DWORD 并浮动提示。
- **对齐方式**：协议无对齐参数，下拉仅 UI 展示，不参与搜索。
- **hex 编辑器**：无 androidx/RecyclerView 依赖，用 ListView 每行 16 字节渲染；点击行=选中（`#331E6FBA` 高亮），长按=操作栏。
- **结果区域列**：结果事件不带区域字段，按 `gg_target_info` 的 maps 分类（anon/heap/stack/code）。
- **保存页类型**：本地保存项类型用 GG 缩写（BY/WO/DW/QW/FL/DB），PC 端 annotate 事件的字符串类型自动归一化。
